# The Indicator

Fantasy football analytics interface prototype. Player names, teams, and positions were checked against Sleeper's NFL player directory on 2026-09-19. All scores, projections, usage metrics, signals, historical charts, and narratives are illustrative examples, not verified statistics or fantasy advice.

Run locally with `corepack pnpm install` and `corepack pnpm dev`.

A verified statistics source and permission for commercial use of third-party data are required before monetization.
